# Jewish-Flipper
A centralized database for Jewish community access cards — starting with unlimited mikveh cards, with support for NFC/RFID shul (synagogue) access as well.

Concept

the mikvehs issue their own individual cards (e.g., unlimited-use cards or memberships). This project aims to bring all participating mikveh cards into a single, unified system — so if anyone is traveling or is in a different location you can get here NFC, or RFID  that works across all mikvehs.
